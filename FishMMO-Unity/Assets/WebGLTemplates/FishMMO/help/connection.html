Can't connect to the game?

The game talks to its servers over QUIC, a modern, fast connection type that runs over UDP. Some antivirus programs, firewalls and networks block or intercept it. This page shows how to let the game through.

Start here

  1. Pick your security software below and follow its steps. If you're not sure what you have, check the icons in the bottom-right corner of your taskbar, or open Windows Security and look under Virus & threat protection.
  2. Close your browser completely and open it again, then sign in.
  3. Still stuck? Try a different network, such as your phone's hotspot. If the game works there, the block is on your usual network, not your PC: see Blocked by a network or firewall.

For any exclusion below, these are the addresses to use:

  • Website/domain: *.fishmmo.com (if the field won't take a *, add game.fishmmo.com and play.fishmmo.com one at a time)
  • Server IP address: looking it up…
Please don't turn QUIC or HTTP/3 off in your browser, even if your antivirus suggests it. The game needs it, and turning it off stops the game connecting at all.

Security software

Many antivirus products scan web traffic by decrypting it on your PC. With the game's connection, some answer it themselves and never pass it on, so signing in fails without a clear error. The fix is to exclude the game's addresses from that scanning. Choose yours:

ESET Kaspersky Bitdefender Norton Avast / AVG McAfee Malwarebytes Windows Security only

Steps marked Confirmed have fixed a player's connection. The others are from the vendor's own documentation and haven't been tested with the game yet. If they work for you, or don't, please tell us.

ESET Confirmed

NOD32 Antivirus, Internet Security, Smart Security and ESET HOME Security.

  1. Open ESET and press F5 to open Advanced setup.
  2. Go to Protections → Web access protection and expand Web access protection.
  3. Click Edit next to Excluded IPs, click Add, enter the server IP address (shown above), then click OK → OK.
  4. Still under Web access protection, click Edit next to Address list.
  5. Select List of addresses excluded from content scan, click Edit, then Add, and enter *.fishmmo.com. Type it exactly, including the *. at the start. Click OK → OK.
  6. Click OK to save, then restart your browser.

Kaspersky Untested

Kaspersky Standard, Plus and Premium.

Kaspersky's documentation says it blocks the QUIC protocol. The exclusion below may not be enough. If it isn't, the game can't connect while Kaspersky's protection is running. Please let us know so we can look for another way.
  1. Open Kaspersky and click Settings (bottom of the main window), then Security settings.
  2. In the Advanced settings block, open Network settings.
  3. Under Encrypted connections scan, click Configure trusted addresses, then Add. Enter game.fishmmo.com as the domain name and click Add. Repeat for play.fishmmo.com.
  4. If you play the desktop version, also use Configure trusted applications on the same page to add the game.
  5. Restart your browser and try again.

Bitdefender Untested

Total Security, Internet Security and Antivirus Plus.

Bitdefender's own help suggests turning off QUIC/HTTP/3 in your browser. Please don't: the game needs it. Use the exception below instead.
  1. Open Bitdefender and click Protection.
  2. In the Online Threat Prevention pane, click Settings, then Manage exceptions.
  3. Click + Add an Exception, enter the server IP address (shown above), turn on the switch next to Online Threat Prevention, and click Save. Add game.fishmmo.com and play.fishmmo.com the same way.
  4. If it still won't connect, go back to Online Threat Prevention → Settings and turn off Encrypted web scan to test. If that fixes it, tell us, so we can confirm the right exception.

Norton 360 Untested

  1. Open Norton, click Security in the left pane, then go to Advanced Security → Web → Safe Web.
  2. On the Exclusions tab, click Add and add game.fishmmo.com and play.fishmmo.com.
  3. On the Settings tab of the same page, Norton has a QUIC/HTTP3 scanning switch. If the exclusion isn't enough, turn this off.
  4. Desktop version: if Norton's firewall asks about the game, allow it. To check, go to Advanced Security → Network → Smart Firewall → Program Control and set the game to Allow.

Avast and AVG Untested

Avast Free Antivirus, Avast Premium Security, AVG AntiVirus and AVG Internet Security.

  1. Open the app and go to ☰ Menu → Settings.
  2. Go to General → Exceptions, click Add exception, and choose the Website / Domain tab. Add fishmmo.com.
  3. If that isn't enough, find the web protection settings. In Avast this is Scam Guardian → Web Guard (older versions: Protection → Core Shields → Web Shield). Untick Enable QUIC/HTTP3 scanning.
  4. Desktop version with Avast Premium's firewall: allow the game under Protection → Firewall → Settings → View Firewall rules → Application rules.

McAfee Untested

McAfee doesn't document whether it scans or blocks QUIC. If you use McAfee's firewall and play the desktop version, make sure the game is allowed: open McAfee, find Firewall, and allow the game under its program or app connection settings. If the browser version won't connect either, please contact us and tell us your McAfee product. You'll help us write proper steps.

Malwarebytes Untested

  1. Open Malwarebytes and go to Detection History → Allow List.
  2. Click Add, choose Allow a website, and add the server IP address (shown above). Add game.fishmmo.com too.
  3. Desktop version: also add the game as an application that connects to the Internet.

Windows Security only

Windows' built-in protection doesn't intercept the game's connection, and Windows Firewall lets outgoing connections through by default. If you only have Windows Security and the desktop version won't connect, check that the game isn't blocked:

  1. Open Windows Security → Firewall & network protection → Allow an app through firewall.
  2. Click Change settings. If the game is in the list, tick both boxes. If it isn't, use Allow another app to add it.

If it still fails, see Blocked by a network or firewall.

Blocked by a network or firewall

If the game says it couldn't reach the login server, the connection never got through. Common causes:

  • School, work, hotel or public Wi-Fi. Many of these block everything except ordinary web browsing. Try another network, such as your phone's hotspot. If the game works there, ask the network's administrator to allow outgoing UDP to game.fishmmo.com on ports 7770, 7780 and 7790.
  • Antivirus with its own firewall. Allow the game, or your browser, in its firewall settings. See your product's section above.
  • VPN or proxy. Some don't carry UDP. Turn it off and try again.
  • Your router. This is rare, but some routers have UDP or "game" filtering. Check its security settings.
  • The server is down. If nothing else helps, the server may be restarting. Wait a few minutes.

Browsers

Use an up-to-date Chrome, Edge or Firefox. The game needs WebGPU and WebTransport, both built into these browsers. Don't turn off QUIC in chrome://flags or network.http.http3.enable in Firefox. The game won't connect without them.

Still can't connect? Contact us, and include the name of your security software and the message the game showed.
